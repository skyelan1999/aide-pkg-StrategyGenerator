# Strategy Generator
This is an independent public MIT Aide plugin. Keep the deterministic generator, UI, tests and delivery records here. Do not modify Aide core, existing user profiles, model providers or approval policies. No network, model calls, credentials, telemetry, disk writes or browser persistence in runtime code. The token estimator is heuristic, not an exact tokenizer. Recommendations are not benchmarks or guaranteed optimal settings. Keep Aide profile parameters separate from session/model settings; do not provide a destructive profiles.json replacement or claim automatic application.
Track public feature/acceptance work centrally in skyelan1999/aide Issues, linking this implementation repo, Release and marketplace changes. Publish only allowlisted package files. Test with synthetic inputs. Browser acceptance is required for UI changes; distinguish fixture, isolated-host and actual installed evidence.
