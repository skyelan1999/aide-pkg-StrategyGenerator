# Strategy Generator 0.2.0

工作台通过现有主题协议跟随 Aide 的四套配色及明暗切换；旧宿主或独立预览使用系统主题。

新增十个型号/模式预设：OpenAI 推理、Codex Bridge、DeepSeek 思考/非思考、Qwen3 原版思考/非思考、Qwen3.6-27B 思考/非思考、Claude 现代推理和 Gemini 3.x。每项展示官方来源、模式边界与经验建议；Qwen 官方采样组合与通用单项调参分开，服务侧字段单独展示。

继续保留九类用途、可解释预算、复制兜底、JSON 下载和三个只读计算工具。独立公开 MIT，无运行时网络、模型调用、API Key、持久化或自动应用。

20 个 Node 测试、2 个发布身份测试；Chromium 验收与隔离 Aide 宿主验证记录见 docs/ACCEPTANCE-0.2.0.md。型号资料核对日期 2026-11-24；经验建议不是新增模型实测或最优参数保证。Codex Bridge 输出预算不是 CLI 严格执行上限。
